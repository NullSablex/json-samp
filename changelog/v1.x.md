# Changelog — v1.x

Histórico do período de código fechado (proprietário). Nenhuma destas versões
chegou a ser publicada.

## [1.2.3] — 17/08/2025

Estado final da linha 1.x. Expansão para I/O de arquivos e API genérica de
acesso por caminho.

### Added

- Arquivos: `json_open_file`, `json_save_file`, `json_create_file`, `json_reload_file`.
  - Caminhos relativos são resolvidos sob `scriptfiles/`.
- Objetos/arrays (nível 1): `json_append_array`, `json_delete_key`, `json_exists_key`,
  `json_object_len`, `json_object_key_at`, `json_array_len`, `json_array_get_string`.
- API genérica por caminho (JSON Pointer `/a/b` e sintaxe amigável `a.b[0].c`):
  `json_exists_at`, `json_get_string_at`, `json_get_int_at`, `json_get_float_at`,
  `json_get_bool_at`, `json_type`, `json_len`, `json_key_at`, `json_item`, `json_at`,
  `json_set_at`, `json_delete_at`.

## [1.1.1] — 17/08/2025

### Added

- `json_get_string`, `json_set_bool`, `json_set_int`, `json_set_float`.

## [1.0.1] — 17/08/2025

Versão inicial do plugin.

### Added

- Parse/free: `json_parse`, `json_free`.
- Getters (nível 1): `json_get_int`, `json_get_float`, `json_get_bool`.
- Validação/consulta: `json_is_valid`, `json_has_key`.
- Criação/escrita: `json_create`, `json_set_string`, `json_to_string`.
- Pool global de documentos indexado por ID.
- Logger com banner do plugin.
